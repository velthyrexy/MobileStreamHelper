📱 Mobile Stream Helper

A simple Android overlay tool designed to help mobile streamers display custom text and images on top of their screen.

Languages: 🇬🇧 English · 🇹🇷 Türkçe · 🇩🇪 Deutsch · 🇪🇸 Español · 🇫🇷 Français

---

🇬🇧 English

✨ Features

- 📝 Add custom text overlays
- 🖼️ Add custom images
- 🎨 Customize text color
- 🔤 Choose different fonts
- 💡 Change text opacity
- 🖌️ Customize text outline thickness and color
- 📐 Adjust image position
- 📏 Adjust image width and height
- 👆 Move overlay elements by dragging
- 📱 Display overlays above other applications
- 🌑 Dark/purple interface

🚀 Getting Started

1. Download

Download the latest APK from the Releases section of this repository.

2. Install

Android may warn you that the application was downloaded from an unknown source.

If you trust the source:

1. Open the downloaded APK.
2. Allow your browser/file manager to install unknown apps if Android asks.
3. Install the application.

3. Overlay Permission

When you press Start Overlay, Android may ask for permission to display over other applications.

Enable:

Allow display over other apps

This permission is required for the overlay system.

---

📝 Adding Text

1. Open Mobile Stream Helper.
2. Press Add Text.
3. Enter the text you want to display.
4. Adjust the text size.
5. Select a font.
6. Select a text color.
7. Adjust opacity.
8. Adjust outline thickness.
9. Select an outline color.
10. Press Add Text.

The text will appear in the preview area.

👆 Moving Text

Touch and hold the text, then drag it to the desired position.

---

🖼️ Adding an Image

1. Press Add Image.
2. Select an image from your device.
3. The image will appear in the preview.
4. Adjust its position and size using the image settings.

You can change:

- X position
- Y position
- Width
- Height

---

🎬 Starting the Overlay

When your overlay is ready:

1. Press Start Overlay.
2. Grant overlay permission if requested.
3. The overlay service will start.
4. You can now use the overlay while using another application.

---

⚠️ Permissions

Display over other apps

The application requires the Android overlay permission to display text and images above other applications.

The application does not need this permission for normal editing/preview functionality.

Only enable permissions you are comfortable granting.

---

🔐 Privacy

Mobile Stream Helper is designed to operate locally on your Android device.

The project does not require an account to create overlays.

Do not add private information, passwords, API keys, or signing keys to this repository.

---

🛠️ For Developers

This project is an Android application written in Kotlin.

Main components include:

- "MainActivity"
- "TextEditorActivity"
- "ImageEditorActivity"
- "GuideActivity"
- "LanguageActivity"
- "OverlayService"
- "OverlayData"

Building the project

Clone/download the repository and open it in Android Studio or another compatible Android development environment.

Then build the debug APK using:

./gradlew assembleDebug

The generated APK can be found under:

app/build/outputs/apk/debug/

🚀 Başlangıç

1. İndir

Bu repository'nin Releases bölümünden en son APK'yı indirin.

2. Kur

Android, internetten indirilen APK'lar için bilinmeyen kaynak uyarısı gösterebilir.

Kaynağa güveniyorsanız:

1. İndirdiğiniz APK'yı açın.
2. Android isterse kullandığınız tarayıcıya/dosya yöneticisine bilinmeyen uygulama yükleme izni verin.
3. Uygulamayı kurun.

3. Overlay İzni

Start Overlay butonuna bastığınızda Android overlay izni isteyebilir.

Şu izni etkinleştirin:

Diğer uygulamaların üzerinde göster

Overlay sisteminin çalışması için bu izin gereklidir.

---

📝 Yazı Ekleme

1. Mobile Stream Helper uygulamasını açın.
2. Add Text butonuna basın.
3. Görünmesini istediğiniz yazıyı girin.
4. Yazı boyutunu ayarlayın.
5. Font seçin.
6. Yazı rengini seçin.
7. Opaklığı ayarlayın.
8. Outline kalınlığını ayarlayın.
9. Outline rengini seçin.
10. Add Text butonuna basın.

Yazı önizleme alanında görünecektir.

👆 Yazıyı Taşıma

Yazının üzerine dokunun ve basılı tutarak istediğiniz yere sürükleyin.

---

🖼️ Resim Ekleme

1. Add Image butonuna basın.
2. Cihazınızdan bir resim seçin.
3. Resim önizleme alanında görünecektir.
4. Resim ayarlarından konumunu ve boyutunu değiştirin.

Ayarlanabilen özellikler:

- X konumu
- Y konumu
- Genişlik
- Yükseklik

---

🎬 Overlay'i Başlatma

Overlay'iniz hazır olduğunda:

1. Start Overlay butonuna basın.
2. İstenirse overlay iznini verin.
3. Overlay servisi başlayacaktır.
4. Artık başka bir uygulamayı kullanırken overlay'inizi gösterebilirsiniz.

---

⚠️ İzinler

Diğer uygulamaların üzerinde göster

Uygulama, yazı ve resimleri diğer uygulamaların üzerinde gösterebilmek için Android overlay iznini kullanır.

Bu izin yalnızca overlay özelliği için gereklidir.

Kendinizi rahat hissetmediğiniz izinleri etkinleştirmeyin.

---

🔐 Gizlilik

Mobile Stream Helper mümkün olduğunca cihaz üzerinde yerel olarak çalışmak üzere tasarlanmıştır.

Overlay oluşturmak için hesap oluşturmanız gerekmez.

Bu repository'ye şifre, API key veya signing key gibi gizli bilgileri yüklemeyin.
